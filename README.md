# U.S. History 1492 to Reconstruction, Spring: unsparkled archive

The plain, unsparkled originals of the lessons and primary-source pages of the Spring course (Canvas course 289), at the same paths as the live lesson repo `optimaondemand/mjushistory-lessons-spring`. Nothing in this repo is ever edited, and no sparkled file is ever pushed here.

- `weeks/week-NN/lesson-NN-M.html`, `primary-source-1.html`, `primary-source-2.html`: the plain pages. Founding Era pages (weeks 19 and 20) are the versions from just before they were sparkled; all other weeks were copied unchanged from the live repo before sparkling began.
- `canvas-289/founding-era/`: plain bodies of eight Founding Era Canvas items, from the course's build source files.

Created 2026-11-20.
